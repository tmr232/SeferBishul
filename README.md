# Sefer Bishul

## תגיות וניווט

אפשר לשייך מתכון לכמה תגיות בעזרת חזית YAML בתחילת קובץ המתכון:

```markdown
---
תגיות:
  - טיגון עמוק
  - חנוכה
---
# סופגניות

## חומרים
...

## הכנה
...
```

אפשר גם לכתוב `תגיות: [טיגון עמוק, חנוכה]`. שמות התגיות חייבים להיות
מחרוזות לא ריקות; רווחים בקצוות ותגיות כפולות מנוקים בבנייה.
מתכונים ללא חזית או ללא תגיות ממשיכים לעבוד כרגיל.

הבנייה יוצרת את `tags.html`: מסך תגיות בשתי עמודות, עם קישור לכל
המתכונים המשויכים לכל תגית. הצבע והכתובת של כל תגית נקבעים מהשם שלה
ונשארים קבועים גם כשמוסיפים תגיות אחרות, ללא תלות בדפדפן או במכשיר.
קישורים לתגיות מופיעים בתוכן העניינים, בגלריה ובמתכונים עצמם.
הקטגוריה של כל מתכון לפי התיקייה שלו נכללת אוטומטית גם כתגית, בנוסף לתגיות
שבחזית המתכון. בתיקיות מקוננות משתמשים בנתיב היחסי המלא, כמו בתוכן העניינים
(למשל `חגים/חנוכה`). אם אותה תגית מופיעה גם בחזית, היא נכללת פעם אחת בלבד.
מתכונים בתיקיית `recipes` עצמה לא מקבלים תגית תיקייה.
החלוקה הקיימת לקטגוריות בתוכן העניינים נשארת ללא שינוי.

## פיתוח

נדרשים Python 3.15.2, uv 0.13.8 ו־Bun 1.4.4. גרסאות Python ו־Bun
מוגדרות גם בקבצים `.python-version` ו־`.bun-version`.

```sh
uv sync --locked
bun install --frozen-lockfile
uv run --locked nox -s lint test build
```

לעיצוב הקוד: `uv run --locked nox -s format`. Ruff מעצב ובודק את קוד
Python, ו־mypy בודק טיפוסים. Biome אחראי רק לעיצוב JavaScript ו־JSON;
oxlint אחראי לבדיקות JavaScript, ללא כללי עיצוב מתחרים. בדיקות JavaScript
בתיקיית `tests` רצות באמצעות Bun, כולל קובצי `.test.mjs`.

תלויות Python נעולות ב־`uv.lock`, ותלויות כלי JavaScript ב־`bun.lock`.
לאחר שינוי תלויות מריצים `uv lock --upgrade` או `bun update` בהתאמה.
תלויות GitHub Actions, כולל תלויות עקיפות, נעולות ב־`.github/workflows/actions.lock`.
לאחר שינוי workflow מעדכנים ומוודאים את הנעילה:

```sh
gh extension install github/gh-actions-lock --pin v0.4.1
gh actions-lock
gh actions-lock --verify
```

האתר נוצר בתיקיית `public`. אפשר להגיש אותה באמצעות שרת קבצים סטטי;
הניווט בתגיות אינו דורש JavaScript או שרת יישום.
