# Sefer Bishul

## תגיות וניווט

אפשר לשייך מתכון לכמה תגיות בעזרת חזית YAML בתחילת קובץ המתכון:

```markdown
---
תגיות:
  - טיגון עמוק
  - חנוכה
---
# סופגניות

## חומרים
...

## הכנה
...
```

אפשר גם לכתוב `תגיות: [טיגון עמוק, חנוכה]`. שמות התגיות חייבים להיות
מחרוזות לא ריקות; רווחים בקצוות ותגיות כפולות מנוקים בבנייה.
מתכונים ללא חזית או ללא תגיות ממשיכים לעבוד כרגיל.

הבנייה יוצרת את `tags.html`: מסך תגיות בשתי עמודות, עם קישור לכל
המתכונים המשויכים לכל תגית. הצבע והכתובת של כל תגית נקבעים מהשם שלה
ונשארים קבועים גם כשמוסיפים תגיות אחרות, ללא תלות בדפדפן או במכשיר.
קישורים לתגיות מופיעים בתוכן העניינים, בגלריה ובמתכונים עצמם.
הקטגוריה של כל מתכון לפי התיקייה שלו נכללת אוטומטית גם כתגית, בנוסף לתגיות
שבחזית המתכון. בתיקיות מקוננות משתמשים בנתיב היחסי המלא, כמו בתוכן העניינים
(למשל `חגים/חנוכה`). אם אותה תגית מופיעה גם בחזית, היא נכללת פעם אחת בלבד.
מתכונים בתיקיית `recipes` עצמה לא מקבלים תגית תיקייה.
החלוקה הקיימת לקטגוריות בתוכן העניינים נשארת ללא שינוי.

## פיתוח

```sh
uv sync
uv run nox -s lint test build
```

האתר נוצר בתיקיית `public`. אפשר להגיש אותה באמצעות שרת קבצים סטטי;
הניווט בתגיות אינו דורש JavaScript או שרת יישום.

## התקנה כאפליקציה

אפשר להתקין את [ספר המתכונים](https://tmr232.github.io/SeferBishul/)
לגישה ממסך הבית. ההתקנה פותחת את תוכן העניינים בחלון עצמאי בדפדפנים
תומכים; כל המתכונים ודפי התגיות נכללים בתחום האפליקציה.

- באנדרואיד: פותחים בכרום ובוחרים באפשרות ההתקנה בתפריט הדפדפן.
  האפשרות והניסוח משתנים לפי הדפדפן והמכשיר; בחלקם מתקבל קיצור דרך בלבד.
- באייפון ובאייפד: פותחים בספארי, בוחרים שיתוף ואז ״הוסף למסך הבית״.
  אם מוצג המתג ״פתח כיישום אינטרנט״, משאירים אותו פעיל.
  אין חלונית התקנה אוטומטית כמו בחלק מדפדפני כרומיום.
- במחשב: כרום ואדג׳ תומכים בהתקנה מתפריט הדפדפן; בספארי במק
  נתמך אפשר לבחור ״הוסף ל־Dock״. בדפדפנים אחרים התמיכה משתנה,
  ואין להניח שתופיע אפשרות להתקנת אפליקציה.

נדרש חיבור לאינטרנט לקריאת המתכונים גם לאחר ההתקנה. לא נוסף מטמון
לשימוש לא מקוון, ולא נרשם עובד שירות. אין הבטחה להצגת כרזת התקנה אוטומטית;
אפשר להשתמש בתפריט הדפדפן כאשר הוא תומך בכך.

הבנייה מעתיקה את המניפסט והסמלים מתוך `src/sefer_bishul/static`.
הקישורים יחסיים, כולל מתוך מתכונים בתיקיות מקוננות, כך שאותה בנייה מתאימה
גם לנתיב האירוח הנוכחי `/SeferBishul/` וגם לאירוח בשורש אתר.
יש להגיש את האתר בחיבור מאובטח; בפיתוח מקומי אפשר להשתמש בשרת מקומי.
